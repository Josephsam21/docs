LASUMedScreen is a production-ready platform that digitizes the entire student medical screening and clearance lifecycle — from initial health form submission to final clearance approval. Built for universities and academic institutions, it replaces paper-based processes with a fast, secure, and role-aware web application.

## Get Started in 4 Steps

<Steps>
  <Step title="Clone and install">
    Clone the repository and install dependencies with your preferred package manager.
  </Step>
  <Step title="Configure environment">
    Set up your Supabase project, Resend API key, and copy `.env.example` to `.env.local`.
  </Step>
  <Step title="Run locally">
    Start the development server with `npm run dev` and visit `http://localhost:3000`.
  </Step>
  <Step title="Deploy to production">
    Push to Vercel or your preferred host with the correct environment variables set.
  </Step>
</Steps>
